# ALFWorld 评论模型与信用分配实验总结

更新日期：2026-08-15

## 1. 结论摘要

当前最好的单个结果来自 **2+2 层双评论模型的 best checkpoint（step 145）**：

- seen-140：87.86%（123/140），测试得分 6.131；
- unseen-134：81.34%（109/134），测试得分 5.006。

现有证据支持三点：

1. **轻量评论模型很可能是有效模块。** 单评论模型中，2 层版本相对完整 28 层版本更快，seen-32 和 unseen-134 均更好；双评论模型中，2+2 层在由 seen 选出的 best checkpoint 上也同时优于 28+28 层。
2. **跨观察信用更像是泛化模块，而不是稳定提高 seen 的模块。** 它相对普通 2 层近端策略优化在 seen-140 上低 1.43 个百分点，但在 unseen-134 上高 10.45 个百分点。
3. **轮次信用与令牌残差的双粒度组合有明确正向证据。** 无论评论模型是 2 层还是 28 层，双评论模型的 best/latest checkpoint 在 unseen 上都超过跨观察单评论模型；但当前实验还不能把增益单独归因于轮次分支或令牌残差中心化。

完整 28 层双评论模型没有带来稳定的性能优势，却显著增加训练时间。它的 latest checkpoint 在 unseen 上略高于两层 latest，但其 seen、best unseen 和总体计算效率均较差，因此当前结果不支持“更大评论模型更好”。

## 2. 统一实验设置

- 智能体：`Qwen2.5-1.5B-Instruct`，actor 始终使用完整 28 层模型。
- 训练资源：8 张 GPU。
- 训练长度：150 个策略更新步。
- 每步总 rollout 数：约 128。
- 近端策略优化变体：128 个任务，每个任务采样 1 条轨迹。
- 组内相对策略优化：16 个任务，每个任务采样 8 条轨迹。
- 最大环境步数：50。
- actor 学习率：`1e-6`；评论模型学习率：`1e-5`。
- 策略约束：系数 `0.01` 的低方差散度损失。
- seen 测试集：`eval_in_distribution`，完整规模 140。
- unseen 测试集：`eval_out_of_distribution`，完整规模 134。
- 正式 unseen 测评：温度 0.4、采样开启、环境种子 0。

需要注意两种验证口径：早期基线训练期间只监控 32 个 seen 任务；后期双评论模型每 5 步验证完整 140 个 seen 任务。32 任务曲线只能用于观察同口径趋势，不能和 140 任务曲线直接排序。

## 3. 做过的主要实验

| 编号 | 方法 | 评论模型 | 奖励与优势估计 | 目的 |
|---|---|---|---|---|
| M1 | 标准近端策略优化 | 1 个完整 28 层评论模型 | 每个动作内部做令牌级广义优势估计；旧实现将整轮奖励放到每个动作的最后有效令牌 | 原始基线 |
| M2 | 2 层单评论模型 | 词嵌入 + 前 2 层 Transformer + 标量价值头 | 与 M1 相同 | 只消融评论模型容量 |
| M3 | 跨观察单评论模型 | 1 个 2 层评论模型 | 使用逐动作环境奖励；跳过观察，把同一轨迹的动作令牌连接后做广义优势估计 | 复现 SAO 风格的跨观察信用部分 |
| M4 | 2+2 层双评论模型 | 2 层令牌评论模型 + 2 层轮次评论模型 | 跨观察令牌信用 + 轮次信用 + 动作内令牌残差 | 当前轻量双粒度方法 |
| M5 | 28+28 层双评论模型 | 两个完整 28 层评论模型 | 与 M4 相同 | M4 的严格容量消融 |
| M6 | 组内相对策略优化 | 无评论模型 | 同任务 8 条轨迹按结果奖励做组内相对优势 | 无评论模型基线 |

### 3.1 评论模型初始化

2 层评论模型不是随机训练的小 Transformer。它加载千问的预训练词嵌入和前 2 个 Transformer 层，再接一个新初始化的标量价值头；可训练参数约为 3.27 亿。完整评论模型加载全部 28 层并接同类价值头。双评论模型中的两个分支独立初始化和更新，不共享参数。

当前双评论模型也不是“读取 actor 隐状态的隐藏思维评论模型”。两个评论模型会独立重新编码文本；令牌分支对动作令牌估值，轮次分支取每个动作第一个有效令牌位置作为动作边界的价值代理。

### 3.2 跨观察信用

普通实现将每个动作视为独立的令牌序列。跨观察实现保留观察作为下一次生成的条件，但观察不进入策略损失，并将有效动作令牌按轨迹顺序连接：

```text
动作 1 的令牌 -> 动作 2 的令牌 -> ... -> 终局动作令牌 -> 环境奖励
```

该实验只复现了跨观察优势递推，没有实现 SAO 的异步采样、重要性修正和价值更新调度，因此不能称为完整 SAO 复现。

### 3.3 双评论优势

令第 `k` 个动作中第 `j` 个令牌的跨观察优势为 `A_token(k,j)`，轮次评论模型给第 `k` 个动作的整体优势为 `A_turn(k)`。当前 actor 使用：

$$
A_{k,j}^{\mathrm{hybrid}}
= A_k^{\mathrm{turn}}
+ \alpha\left(
A_{k,j}^{\mathrm{token}}
- \frac{1}{|a_k|}\sum_{u \in a_k}A_{k,u}^{\mathrm{token}}
\right),\qquad \alpha=1.
$$

轮次优势决定一个动作的平均更新方向，零均值令牌残差保留动作内部不同令牌的信用差异。令牌分支使用 `gamma=1, lambda=1`；轮次分支使用 `gamma=1, lambda=0.95`。

## 5. 模块有效性判断

### 5.1 有较强正向证据的模块

**轻量评论模型。** M2 相比 M1 在 step 150 的 seen-32 高 9.38 个百分点、unseen-134 高 11.19 个百分点，同时减少约四分之一训练时间。M4 与 M5 的严格容量消融中，两层版本的 best seen 高 5.71 个百分点、best unseen 高 8.96 个百分点，训练时间少约三分之一。

**双粒度信用。** 相对 M3，M4 latest 的 seen-140 高 14.29 个百分点、unseen-134 高 8.21 个百分点；M5 latest 的 seen-140 高 7.86 个百分点、unseen-134 高 10.45 个百分点。这个增益在两种评论模型容量下都存在，因此不是单纯由评论模型变小造成的。

**完整任务索引验证。** seen-140 和 unseen-134 的逐索引重置修复避免了重复抽到少量任务。它不是训练算法贡献，但显著提高了实验结论的可信度；32 任务监控值经常高估完整测试表现。

### 5.2 有正向迹象但归因仍不确定的模块

**跨观察信用。** M3 相比 M2 在 seen-140 低 1.43 个百分点，却在 unseen-134 高 10.45 个百分点。这支持它改善分布外泛化，但不支持“它全面提高训练任务表现”。此外，M3 同时把旧的整轮奖励复制方式改成了逐动作环境奖励，所以当前无法把收益完全分解为“跳过观察”与“奖励放置正确”两部分。

**轮次分支与令牌残差中心化。** M4/M5 同时加入独立轮次评论模型和动作内零均值令牌残差。双评论整体有效，但尚未做只移除轮次分支或只移除残差中心化的正交消融，因此不能确认哪一部分贡献更大。

**checkpoint 选择。** M4 的 seen 和 unseen 都是 step 145 优于 step 150；M5 则 seen 在 step 145 更好、unseen 在 step 150 更好。由 seen 选出的 best checkpoint 不一定也是 unseen 最优，说明模型容量与训练后期泛化之间存在 checkpoint 依赖。

### 5.3 当前看没有收益或尚未真正实现的模块

**完整 28 层双评论模型。** 它比 2+2 层版本多消耗约 21 小时训练时间，best seen 和 best unseen 都更低。虽然其 latest unseen 比两层 latest 高 2.24 个百分点，但不足以抵消 best 结果、seen 表现和计算成本上的劣势。

**早期结构化进度价值试验。** 该版本的目标包含 episode 长度和剩余步数惩罚，本质上混入了奖励塑形；它不能证明“结构化小价值函数比近端策略优化评论模型更准”，因此不进入主结果表，也不适合作为当前核心贡献。

**纯轮次级近端策略优化。** 当前没有运行纯轮次版本。M4/M5 最终仍对动作令牌更新，只是令牌共享轮次优势的平均方向，因此不能把结果归因于纯 Turn-PPO。

**actor 隐状态融合、共享主干双头评论模型、图记忆和技能库。** 这些仍是后续设计想法，没有进入上述六个正式实验，当前结果不能支持相关结论。

## 6. 可以用于汇报的结论

1. 评论模型容量存在明显的“越大不一定越好”现象；在有限在线轨迹下，2 层预训练评论模型提供了更好的性能与效率平衡。
2. 跳过观察的跨动作令牌信用对 unseen 泛化有明显帮助，但对 seen 的收益不稳定，并与逐动作奖励修正存在归因耦合。
3. 在跨观察令牌信用之上加入轮次信用，能进一步提高长程智能体策略；最强结果为 seen-140 87.86%、unseen-134 81.34%。
4. 双评论方法当前仍有计算冗余。最自然的下一版是一个共享的 2 层文本主干，加令牌价值头和轮次价值头，在保持双粒度目标的同时只做一次文本编码。
5. 下一项关键消融应固定两层共享主干和完整 140/134 评测口径，分别关闭轮次分支、令牌残差中心化和跨观察递推，从而确定真正产生收益的最小模块组合。
